运维提示

  • 升级时先执行 botguard-ctl migrate up，再滚动替换 gateway；库结构落后时 gateway 的 /readyz 会返回 schema_outdated。
  • 管理后台和 gateway 必须使用同一个 BOTGUARD_SECRET_KEK；更换 KEK 时把旧值放进 BOTGUARD_SECRET_KEK_PREVIOUS。
  • 忘记管理员密码：在服务器上执行 botguard-ctl admin reset-password -username 用户名。
  • 统计数据存在 Redis，按小时保留 32 天；审计日志存在 MySQL 的 sys_audit_log 表，不会自动清理。
